# 💰 ExpensePro – Smart Financial Tracker

ExpensePro is a full-stack web application designed to help users track daily expenses, manage monthly budgets, and analyze spending patterns using interactive charts. It provides a secure and user-friendly platform for personal finance management.

---

## 🚀 Features

- 🔐 Secure user authentication (Login/Register with BCRYPT hashing)
- 📊 Real-time dashboard with expense summary
- 💰 Monthly budget tracking with alerts
- 📈 Data visualization using Google Charts (Pie & Bar charts)
- 🧾 Full CRUD operations (Add, Edit, Delete, View expenses)
- 📂 Custom category management (Food, Rent, Transport, etc.)
- ⚠️ Over-budget alerts when spending exceeds 80%
- 🖨️ Printable reports for offline use

---

## 🛠️ Tech Stack

- **Backend:** PHP 8.2  
- **Database:** PostgreSQL  
- **Frontend:** HTML5, CSS3, JavaScript  
- **UI Framework:** Bootstrap 5  
- **Icons:** FontAwesome  
- **Charts:** Google Charts API

## 🔧 Installation

1. Clone the repository:

git clone https://github.com/sahilrakshe14/ExpensePro-Expense-Tracker.git


2. Create PostgreSQL database:

expense_tracker


3. Import the SQL file (tables: users, categories, expenses)

4. Configure database in `functions.php`

5. Run using XAMPP:

http://localhost/expense_tracker/
